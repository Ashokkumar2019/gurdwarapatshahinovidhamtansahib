# Dhamtan Sahib — Phase 1

A Vite + React multilingual foundation for the Dhamtan Sahib website.

## Included

- Punjabi (default), Hindi and English language switcher
- Responsive professional homepage
- Reusable React components
- Hero, About/History, highlights, gallery preview, visitor information and footer
- Basic SEO metadata in `index.html`
- No backend yet — Phase 1 uses local/static content
- Ready for GitHub and Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`

No environment variables are required for Phase 1.
